### 🚀 Featured Projects

- 🧠 [Virtual Assistant with LLM + RAG for UAGro](https://github.com/irvingpichardo/llm-uagro-assistant): A chatbot powered by local LLMs (Gemma, LLaMA, DeepSeek) using RAG and Prompt Engineering, integrated into a university website via Flask and Joomla.
- 🧪 [PDF Question-Answering System with FAISS](https://github.com/irvingpichardo/llm-pdf-rag): Upload PDFs, vectorize with `sentence-transformers`, retrieve context via similarity search and generate natural answers with LLMs.
- 📊 [Student Socioemotional Survey Frontend](https://github.com/irvingpichardo/joomla-survey-module): Embedded HTML/CSS responsive module for university-wide student data collection in Joomla.
- 🖱️ [Ghost Cursor Overlay Chrome Extension](https://github.com/irvingpichardo/ghost-cursor): Visual enhancement extension that injects a floating animated ghost cursor into any webpage.
- 🧩 [LLM Playground Interface](https://github.com/irvingpichardo/llm-playground): A simple interface to interact with based LLMs, including real-time streaming, markdown formatting, and voice output.
